 # 13\. RESILIENCE NFR

 This is one of the main examples.

 The external HTTP call must demonstrate:

 - timeout
- retry
- circuit breaker

 Use Resilience4j.

 Requirements:

```
timeout = 2 seconds

retry:
    max attempts = 3
    wait duration = 200ms

circuit breaker:
    failure rate threshold = 50%
    sliding window size = 10
    open-state wait duration = 10 seconds
```

 Configuration must be externalized in:

```
application.yml
```

 Do not hard-code resilience policies in business logic.
